# ai2 —— 价值网络(M1)

目标:用「全明牌价值网络 V(落子后局面)→ 终局闲家总分分布」代替收官搜索里的「推演到底」,
让抽样世界搜索在所有手牌数(13..25 张)上都能跑。V 是在**真实不完全信息策略**的自对弈上训练的,
所以对 belief 抽样出的世界取平均是合理的一步策略改进(没有 strategy fusion)。

## 目录
| 文件 | 作用 |
|---|---|
| `sim.js` | 整副牌模拟器(可快照/还原),开局流程照搬 `test/ai-h2h.js` |
| `featurize.js` | **特征唯一出处**(Node/浏览器通用):局面 → 128 字节原始记录 → 稀疏二值特征(1420)+ 稠密标量(50);布局写在文件头注释里 |
| `gen-data.js` / `gen-par.js` | 自对弈数据(`egSearch:0`);每种子 1 条在线对局 + K 个偏离分支,配对记录写 `*.pairs.ndjson` |
| `check-g0.js` | G0 体检(牌守恒、标签 = 引擎总分、独立对局循环复核) |
| `export.js` | shard → `.npy`(idx/dense/y/meta) |
| `train.py` | MLP 512-256-128,41 类(总分/5,≥200 并入末箱)交叉熵,按种子留出(seed%10==9) |
| `vnet.js` / `register.js` | 无依赖前向(fp16 权重);把模型注册进引擎 `setVnet` |
| `eval-g2.js` / `report-g2.js` | G2 排序评测(留出 fork 配对) |
| `weights/` | 权重与指标(< 3MB 的才入库);大数据在 scratchpad,不入库 |

## 怎么跑
```
# 1) 数据(并行,可断点续跑;约 2.4 s/种子/核)
node ai2/gen-par.js --seed0=0 --total=6000 --chunk=100 --workers=4 --k=3 --out=<数据目录>
node ai2/check-g0.js <数据目录> 30
# 2) 导出 + 训练
node ai2/export.js <数据目录> <npy目录> --permute=1
python3 -I ai2/train.py --data <npy目录> --tag v1 --steps 20000
# 3) G2:留出 fork 配对的排序评测(4 路并行)
for i in 0 1 2 3; do node ai2/eval-g2.js --dir=<数据目录> --w=ai2/weights/vnet-v1.json --out=g2-$i.ndjson --part=$i/4 & done; wait
node ai2/report-g2.js g2-*.ndjson
# 4) G3:整局同桌对照(VNET 只注册到新版;OVN 打开开关)
VNET=ai2/weights/vnet-v1.json OVN='{"vnet":1}' SEED0=0 node test/ai-h2h.js 80fen-test.html 80fen-test.html 350
# ai-pool:VNET=… OVA='{"vnet":1}' EG=1 node test/ai-pool.js 80fen-test.html 200
```
开关:`AIP.vnet`(0 关,默认)、`AIP.vnetSamples`(30)、`AIP.vnetMaxCands`(4)。网页里目前没有加载模型的入口,开关只在 Node 测试里生效。

## 结果(2026-11-11,M1 第一轮)
数据:5700 种子(1.09M 条记录,每种子 1 条在线 + 3 个偏离分支;egSearch:0),生成约 2.4 s/种子/核(机器空闲时;被占用时 4.3 s)。
划分按种子:训练 4560 / 早停验证 570(seed%10==8)/ 留出 570(seed%10==9)。模型 256-128-64,dropout 0.3,高斯标签平滑 σ=2.5 箱,训练 44 s(4 线程)。权重 `weights/vnet-v2.json`(1.1 MB,fp16)。

| 关 | 结果 |
|---|---|
| G0 | 通过:牌守恒 0 异常 / 109 万条;标签 = 引擎总分;独立对局循环复核 30 个种子总分全一致;同种子重跑字节相同 |
| G1 | 留出 CE 2.617(均匀 3.71;种子 3900 时 2.656,学习曲线还在降,但 512-256-128 + 更强正则没有更好)。E[S] 的 MAE(分)按剩牌桶 25-19 / 18-13 / 12-7 / 6-1 / 全部:**网络 20.8 / 17.7 / 13.7 / 9.1 / 13.5**;(a)已得分+50%余分 30.6 / 25.2 / 20.4 / 15.3 / 20.5;(b)同特征线性 21.3 / 18.1 / 14.5 / 10.7 / 14.5。网络只比线性好 5~15%。20k 种子做不到(约 4~5 小时),用了 5.7k |
| **G2(决定性)** | **不过。** 1710 个留出 fork 配对:启发式 h / 真世界 V / 60 世界平均 V 的符号准确率 58.8 / 53.6 / 53.7%(±1.5),而「在线动作更好」的先验是 56%。按预测改走 dev 的平均收益(级):h +0.004±0.005,vt −0.032±0.013,vw −0.015±0.014;分:+0.08 / −0.55 / −0.22(±0.1~0.35)。预测差与实现差的相关 ≈ 0(|r|<0.04,SE 0.027)。领出/跟牌、各剩牌桶分开看都没有一格 V 显著为正。详表 `weights/g2-v2.report.txt` |
| G3(小样本) | 320 种子×2,默认开关(vnetSamples 30):**−2.06 ±0.96 分/局,−0.045 ±0.018 级/局(t≈−2.5)**,90% 的种子行为不同。egMargin 0.15、60 世界:−0.85 ±0.62 分,−0.006 ±0.012 级(持平,54% 的种子行为不同)。搜索 V 分支 27 ms/次(2 候选×60 世界,不含抽样),整局耗时与对照同量级 |

诊断:V 不是坏的 —— 它跟得上确定的当墩得分(末手两候选的当墩得分差与 V 差相关 0.59,斜率 0.73),真世界与抽样世界的预测相关 0.8(不是抽样器错配);
问题是**可分辨的信号太小**:两个相邻候选实现结局差的标准差 ≈ 20 分,V 的差预测标准差 ≈ 3.7 分,而 V 本身的误差(E[S] 的 MAE 13.5 分)比候选间的真实差大得多。
训练标签是「每条轨迹一个带噪结局」,5.7k 条轨迹对 ~1M 参数的网络是数据饥渴的(早停点在 0.5~3 个 epoch)。
下一步想法见 `docs/notes/ai-progress.md` 的 ai2 一节。
