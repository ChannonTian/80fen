# 「谁手里有什么」统一成一个信念模型 + 手调常数精细化(计划,2026-10-24)

产品方(10-24):「应该探索其他玩家拥有某些可能影响本墩、或未来墩的特定牌的概率对本墩出牌选择的影响,不能只盯着眼前的小问题一个个参数调,
也包括之前的参数有没有暂定了一些随意数字、可以再精细化的。」

## 一、现状

**概率是散的。** 打分器里凡是要问「后面有没有人压得住 / 毙得了 / 握着那张」,各处各算:
`unseenBeats` + `pBeaterIn`(在外均匀发牌的坛子公式 `1 − (1 − 份额)^张数`)、`makeVoidProb`(断门)、`maxHoldIn`(上界)、
`leadSkipSignals` / `holdTopShift`(领出信号)、`declVoidPrior`、`ruffWill`、`oppSpendCeil`……每一处一套口径,彼此不一致。
收官搜索另有一套 `sampleWorld`(按约束补发整副牌),却只在剩 ≤12 张时给搜索用。

**手调常数多。** `AIP` 218 项:0/1 开关 75、拟合的系数数组 8、其余数值 135 —— 其中注释里带测量依据的约 22 个,**约 110 个是定下就没再量过的数**
(全表:`node test/aip-audit.js`)。其中一大类其实是**概率**(`ruffStruct1 0.85` 对手断门时毙我单张的把握、
`ruffStruct2 0.45` / `ruffStruct3 0.25`、`dumpOpp 0.85` / `dumpPartner 0.85`、`partnerHoldAfter 0.72`、`pNoPartnerLeft 0.02`、`handShare 4`、
`kittyPointBias 0.8` …),另一大类是**分值换算**(`tempoWeight 0.35`、`oppTempo 6`、`trumpHoldBase 2.5` / `trumpHoldTop 14`、`jokerPairHold 7`、
`drawTrumpUnit 6`、`leadTrumpPenalty 26`、`probePenalty 12` …)。

## 二、先量了一件事:关键牌的位置估得准不准(`test/belief-calib.js` + `test/fit-belief.js`)

自对弈 1200 副,每墩领出前、对另外三家、对每门「在外最大的那张」,比较估计与真值(检验集是另一半种子):

| 口径 | 副牌门最大那张 | 主里最大那张(多半是王) |
|---|---|---|
| 现在的坛子公式 | 0.530 | 0.664 |
| 坛子 + 出牌信号(拟合) | 0.504 | 0.646 |
| **约束抽样**(`sampleWorld` 60 个世界数频率) | 0.506 | **0.642** |
| **约束抽样 + 出牌信号** | **0.487** | 0.638 |
| (只用整体比例,作对照) | 0.635 | 0.683 |

(对数损失,越小越好。)

- **坛子公式系统性偏低**:估 28% 实 33%(副牌)、估 38% 实 44%(主)。原因是**不一致**:别家已断门时,那些牌只能落在剩下几家,坛子不重新分配。
  庄家握在外最大主:坛子 34%、实 51%(底牌那 8 张进了他手),约束抽样 50%。
- **出牌历史里还有信息**:这门出过 ≥3 张的人更可能握着最大那张(坛子 23%、实 29%);末家压过这门的、领过这门的更可能**没有**;
  庄家握副牌最大那张的更少(19% → 实 15%,扣底时埋掉了)。「有机会领没领」在这里系数为 0 —— 它的信息已经被别的项吸收了。
- 约束抽样**一步就拿到了大部分改进**,再叠信号还能再降一截。

## 三、计划

**① 信念服务(belief):** 每个决策点抽 M 个约束一致的世界(就是 `sampleWorld`,再加出牌信号的似然加权),所有「谁有什么」的问题都从这同一批世界里数:
某家握某张、某家断门、某家主牌几张、后手有没有人压得住我这手 / 毙得了 / 超毙得了、队友压不压得回来。缓存到这一次决策结束。
   - 先只读不用:给 `pBeaterIn` / `makeVoidProb` / `pSurvive` 各配一个从世界数出来的版本,用 `belief-calib` 量谁更准。
   - 再逐个替换(每个都走开关 + 零点对照 + 两把尺子)。教训 2(§〇):替换到处在用的中间量会拆掉旧常数的补偿 ——
     所以**先换「概率」类常数的来源,再按②重新标定「分值」类常数**,两者一起量。
   - 代价:60 个世界约 1~3 ms(Node),界面上无感;收官搜索可以直接复用同一批世界。
**② 「概率」类常数换成信念查询:** `ruffStruct1/2/3`、`dumpOpp`、`dumpPartner`、`partnerHoldAfter`、`pNoPartnerLeft`、`handShare`、`ruffWill*`、
   `kittyPointBias` …… 能从世界里直接数出来的,一律不再手填。
**③ 「分值」类常数重新标定:** 这些是「牌权 / 留一张大牌 / 钓主」值多少分 —— 用定点反事实(`cf-situations` 的做法)按局面量,
   像 `feedP` 那样拟合到窄决策上,而不是全局扫一个数。
**④ 对真人:** 信号似然先用自对弈拟合,真人牌谱攒够后单独拟合一份(真人留王、留对子的习惯不同)—— 这也是「对真人更保守的埋底」那件事的正解。

量具:`belief-calib`(估计 vs 真值)、`cf-situations`(局面级反事实)、`ai-h2h` + `ai-pool`(整局两把尺子)、`records-mistakes`(真人牌谱复查)。

## 四、第 1 步结果(10-24,只读对照,不改决策)

新函数(引擎里,只导出、没有决策在用):`makeBelief(view, plays, M)` —— 约束一致地抽 M 个世界;`pSurviveBelief(X, cl, seats, B)` ——
「我这张压下去能不能活到墩末」逐个世界判:后手对手**拿不拿得出**压我 / 毙我 / 超毙我的牌,乘上**意愿**。

量具 `test/calib-belief.js`(自对弈,第 2 / 3 家压下当前最大的单张,实 = 本队拿下这墩)+ `test/fit-will.js`:

1. **「谁手里有什么」这一层,抽样已经很准:** 后手对手「拿得出」压我的牌 —— 抽样估 59%、按真实手牌 58%;跟本门压 38% vs 32%。
2. **大头的误差在「肯不肯用」:** 他们拿得出时真用的比例从 27% 到 100% 不等(真实手牌上量,10325 个样本):

   | | 他是末家 · 台面有分 | 他是末家 · 0 分 | 不是末家 · 有分 | 不是末家 · 0 分 |
   |---|---|---|---|---|
   | 同门压 | 86% | 52% | 61% | 65% |
   | 毙 | 100% | 94% | 76% | 61% |
   | 超毙 | 96% | 63% | 55% | 27% |

   `pSurvive` 里的意愿是几个手调常数(超毙 0.90 / 0.50、同门压当作必压、`ruffWill` 两档……),整体凑巧校准(估 71% 实 73%),分开看各格都偏。
   所以只把「谁有什么」换成抽样、意愿常数不动,对数损失反而略差(0.394 → 0.400)—— 旧常数在补偿旧坛子的偏差(§〇 教训 2 又一次)。
3. **意愿拟合成小模型(`AIP.willW`,特征:毙 / 超毙 / 同门、末家、台面分、最便宜那张是不是大牌 / 带分、压得住几张、后面还有没有我队友、收官)**,
   和抽样一起用:**检验种子上对数损失 0.394 → 0.351(−11%)**,各类局面、各概率档都校准(跟本门压 现 64% / 新 54% / 实 49%;毙 73% / 79% / 80%)。
4. **速度:** 抽样的上界查询加了缓存后,30 个世界 5.2 ms / 次(60 个 10 ms),30 个和 60 个准确度几乎一样(0.3404 vs 0.3397)。
   收官搜索里同一处也加了缓存,行为逐位相同(零点对照 0/30),整局用时约 −10%。

**注意:** 意愿是对着 AI 对手量的。真人的意愿(留王、留对子)要单独拟合 —— 真人牌谱里每一手都有这些特征,攒够了就能拟合一份。

**下一步(第 2 步):** 把「抽样 + 拟合意愿」接进决策。按教训,不直接全局替换 `pSurvive`,而是:
① 先接在窄决策上(第 2 / 3 家压不压、用哪张压 / 毙),同一套 h2h + pool 量;② 再试全局替换,两者对照;③ 同样的拆法做 `pPartnerTakes`(队友压不压得回来)。

## 五、第 2 步(10-25,进行中):接进决策

**意愿模型通用化**(`test/will-data.js` + `test/fit-will.js`):任何一家「本队暂时输着、手里真有压得过当前最大的牌」时肯不肯压 ——
对手压我、队友压回来、第 3 家接,同一个问题。自对弈 800 副、10298 个样本,对数损失 0.547 → 0.468,各格校准
(加了「末家 × 毙 / 超毙」「同门 × 最便宜那张是大牌」交互项之后)。系数在 `AIP.willWFit`。

**真人意愿**(`test/records-will.js`,牌谱 86 局,后手是真人的样本只有 78 个):方向和 AI 不同 ——
真人断门**几乎必毙**(25/25,AI 同样局面 73%),同门压却**更少用大牌**(60% vs 85%),末家 0 分墩同门压 14%(AI 67%)。
样本还不够拟合一份,攒够了单拟。

**`teamWinBelief`:「这一手之后本队拿下这墩」**,在每个抽样世界里把本墩剩下几家走完(输着、拿得出的按意愿概率用最便宜的那张压,两支加权),
对世界取平均。`test/calib-teamwin.js`,两批检验种子:**对数损失 0.416 → 0.367、0.394 → 0.351**;第 2 家 0.60 → 0.48;
「不压、靠队友压回来」现估 17% / 新 28% / 实 24%。高端略偏乐观(新 85% / 实 71~75%),可以再加一道校准。

**开关 `beliefSurv`(位):** 1 = 跟牌压牌候选用 `pSurviveBelief`;2 = 队友暂大的确定性;**4 = 整个 `pTeamWin`(单张领出、不是末家)换成 `teamWinBelief`**。
改动面:位 4 改变约 15% 的第 2 家决策、5% 的第 3 家(多贴分给后面的队友、少拿 A 去压 K)。

整局(ai-h2h,3 × 350,对 v0.7.41):
| 变体 | 分/局 三批 | 级/局 三批 |
|---|---|---|
| 位 1 | +0.44 / +0.14 / −0.01 | +0.004 / 0.000 / 0.000 |
| 位 2 | −0.13 / +0.08 / +0.11 | −0.004 / −0.003 / +0.002 |
| 位 1+2 | +0.26 / +0.33 / +0.39(约 +0.33 ±0.22) | +0.001 / −0.005 / +0.007 |
| 位 4 | +0.39 / +0.64 / +0.08(约 +0.37 ±0.32) | +0.014 / +0.005 / +0.010(约 +0.010 ±0.007) |

估计准了很多、决策改得不多、整局小正不显著 —— 和「估计准了 ≠ 选择变了」(§三)一致。位 4 在加批次和 pool。
