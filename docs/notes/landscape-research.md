# 横屏布局调研:炉石传说、腾讯升级 / 斗地主,对照我们的横屏(2026-11-04)

产品方:横屏整体还是有些别扭,不如竖屏舒服;参考炉石传说这种横屏手牌游戏的布局和交互,看我们能改什么。

> 参考游戏的做法来自对这几款游戏常见版面的了解,这次没有逐张截图核对;具体尺寸以我们自己量的为准。

## 一、我们现在(v0.7.53)量出来的数

| 尺寸 | 牌桌 | 牌桌占屏 | 左栏 + 右栏 | 手牌宽 / 露出高度 | 桌面牌宽 |
|---|---|---|---|---|---|
| 844×390(iPhone 16e 横放,左右各让 47) | 510×284 | 44% | 100 + 132 = 232(占可用宽度 31%) | 72 / 81 | 89 |
| 932×430(Pro Max 横放) | 574×324 | 46% | 232 | 72 / 81 | 103 |
| 667×375(SE 横放) | 455×297 | 54% | 88 + 116 | 64 / 53 | 79 |
| 1133×650(iPad mini 横放 + Chrome) | 1093×326 | 48% | (宽屏:顶栏 64 + 操作栏 78) | 101 / 222 | 87 |
| 390×844(竖屏,对照) | 370×438 | 49% | — | 67 / 240 | 76 |

别扭在哪:

1. **手机横屏切成三栏。** 左边信息栏、中间牌桌、右边按钮栏,眼睛要在三块之间来回。看手牌在下面、按「出牌」在右边,手指和视线都要跨过去。
2. **手牌比桌上的牌还小。** 844×390 上手牌 72px、只露上面 81px,桌上的牌 89px。手牌是要点、要看的,反而最小;竖屏手牌整张露出来,所以竖屏舒服。
3. **一直挂着、很少用的东西占好位置。** 主 / 级数 / 得分一局里看几眼,托管、清选一局点不了几次,却各占一整块常驻区域。
4. **两侧栏只用了中间一小段高度**,上下都是空的(左栏中间空着,右栏上半截空着)。

## 二、参考游戏怎么做

**炉石传说(横屏卡牌的标杆):**
- 牌桌占满全屏宽,没有侧栏。两位英雄头像在上下中间,随从在中间两排。
- 手牌在屏幕底边,扇形摆开、下半截出屏。手指按住一张,它会**整张抬起、放大**,拖到桌上就是出牌,拖回去就是不出。
- 只有一颗大按钮(结束回合),在牌桌右边缘中间,能做的都做完了它会发光提示。
- 信息都贴在边角:法力水晶在右下,牌库在右边缘,对局历史是左边缘一条小图标,设置是右上角一个齿轮。
- 轮到谁、还剩多少时间:回合快结束时有一根「导火索」在桌面中线上烧过去。

**腾讯欢乐升级 / 拖拉机、欢乐斗地主(和我们同类的扑克):**
- 同样是牌桌铺满全屏,没有侧栏。三家头像贴左、右、上三边,出的牌摆在各自头像朝桌心那一侧。
- 手牌一整排沿底边铺满,牌大、重叠多,只露左上角的点数和花色。选中的牌往上弹起一截。
- 操作按钮(提示 / 出牌 / 不出)**只在轮到你时出现**,浮在手牌正上方,离手指最近;不轮到你就收起来,让出桌面。
- 主牌、级数、分数挤在左上角一小块;菜单、设置在右上角。
- 手指在手牌上横着划过去,能一次选中一串牌(斗地主的「滑动选牌」)。

## 三、可以借鉴的

**A. 版面(推荐先做):全幅牌桌 + 角落信息 + 按钮浮在手牌上方**(示意:[`img/landscape-wireframe.png`](img/landscape-wireframe.png),上半张是现在,下半张是方案)
- 去掉手机横屏的左右两栏,牌桌铺满可用宽度(844×390 上 510 → 约 730px)。上下家的牌摞有地方展开,名牌不再退到上角挤成一排。
- 主 / 级数 / 闲家得分合成左上角一条小签,记录、菜单两个图标放右上角,都压在牌桌角上(牌桌角本来空着)。
- 「出牌」和「问六六」只在轮到你时出现,浮在牌桌右下、手牌正上方;托管挪进菜单(或右上角一个小图标),清选改成「点空白处 / 再点一下取消」。
- 手牌放大(约 88px 宽),压在牌桌下沿上;点中的牌整张抬起。代价是牌桌矮一点(284 → 约 262),桌面牌 89 → 约 82px,换来手牌 72 → 88、牌桌宽 +43%。

**B. 交互(可以单独挑着做):**
1. **点中的牌整张抬起、略放大**(炉石按住放大;我们现在只抬起一点,横屏下抬起来还是只露半截)。
2. **滑动选牌**:手指在手牌上横着划过去,一次选中一串(打拖拉机、甩牌时很省事)。
3. **按钮离手近**:不轮到你时操作区收起,轮到你时在手牌上方出现(上面 A 的一部分,竖屏也可以用)。
4. **轮到谁更醒目**:轮到的那家头像外圈走一圈倒计时(类似炉石的导火索,也给「Bob 等得香蕉都熟了」一个由头)。
5. **上一墩一眼可回看**:炉石左边缘的历史条。我们可以在牌桌角放一个「上一墩」小图标,按住看上一墩四家出了什么,不用打开记录抽屉。

## 四、建议的顺序

1. 先在手机横屏(矮横屏 `m-l`)做 A,iPad 横屏(宽屏两行摆法)跟着用同一套角落信息和浮动按钮。
2. B1、B3 跟 A 一起做(版面一改,按钮位置和手牌大小本来就要动)。
3. B2、B4、B5 单独做,一次一个,方便试玩反馈。

每一步都跑 `play-ui-e2e.js` 的 22 个尺寸(含 4 个带刘海的 iPhone),再请产品方真机看。
