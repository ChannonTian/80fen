# 被实测否掉的改动

**动机站得住 ≠ 改对了。** 这一页把「试过、测了、否掉」的改动集中起来,
免得下一轮(包括我自己)再走一遍。每条都留了开关,数字是配对对照的净收益(分/局)。

想看当时的完整推演,去 [`ai-journal.md`](ai-journal.md) 的同版本章节。

## 一、护底与最后一墩

| 改动 | 开关 | 实测 | 为什么错 |
|---|---|---|---|
| **护底封顶** | `endKittyCap` | 1.0 → **−1.51 ±0.48**(丢最后一墩 40.5%)<br>1.5 → −0.91 ±0.39(36.0%)<br>2.5 → −0.35 ±0.29(32.3%)<br>不封顶 → 基准(28.3%) | 量纲论证是「守最后一墩这个期权不可能比它保护的那笔分更值钱」,听着无懈可击。**测下来不封顶才是对的** —— 那个大数值不是在表达期权价值,是在表达收官阶段的一条硬约束。v0.5.8 猜「等 `bossBase` 重标定后再试」,v0.6.0 重标定后重扫,**推断被推翻** |
| **边际护底下限** | `reserveFloor` | −0.47 | 动机对(`max(0, p最好 − p次好)` 在大王 0.95 + 小王对 0.90 时只有 0.05,「牌越好护底越弱」),补法不对:下限是个常数,真正该算的是**两手护底被同时耗光的联合概率**。这个正确形式至今没建 |
| **埋分的影子成本** | `buryPtShadow` | 0.15 → −0.18 ±0.12<br>0.3 → −0.13 ±0.15<br>0.6 → +0.25 ±0.25 | 推论对:`riskBury` 只算直接损失,没算「为守住这笔底分整局都要留手」。但这个杠杆**推不动** —— shadow 加到 0.6,平均埋底分只从 11.8 掉到 10.7。2×2 交互也显示少埋分只把中盘花主的代价收回三分之一,而丢最后一墩纹丝不动 |

## 从这些失败里提炼出来的五条

1. **动机对 ≠ 方向对。** v0.7.1~v0.7.4 整整四个版本在调「毙多高」,而正确答案是「别毙」。
   先用定点反事实确认方向,再调强度。
2. **量纲错误的大常数,先问它在代偿什么。** 护底不封顶、`bossBase`、`drawTrumpValue` 的符号 ——
   三处答案指向同一个缺口。答不上来就别拆。
3. **触发次数先数。** 一条只触发 9 次的规则,分数打平不说明任何事。
4. **参数形同虚设 vs 参数低杠杆,是两个不同的诊断。** 插桩分清楚再下结论 ——
   这个项目在「以为参数没接上」这件事上错过至少两次。
5. **先查量具和模型里的系统性偏差,再谈参数。** v0.7.15 唯一挣到分的一条(底牌抽样)不是新机制,
   是抽样器里一个方向错了的偏差;同一轮里七条「更聪明」的机制全部打平或掉分。
