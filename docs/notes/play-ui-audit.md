# 打牌 UI 测试页体检与重做(2026-10-18,UI 试验 05)

对象:`80fen-play-ui-test.html`(六六设计系统打牌试验,产品逻辑是测试版 v0.7.39 的分叉)。
做法:Playwright 在 320×568、390×844、844×390、820×1180、1440×900 五个尺寸上从开局打到局终,
加上亮主、扣底、出错牌、问六六、悔牌、拖牌出牌、记录、菜单、设置、分牌、复盘再下一局。

## 查出来的问题

**用不了的(阻断):**
1. 扣底和出牌阶段点选的牌**看不出被选中**:状态里选上了,画面上不抬、不变色(表现层每次重排都把 `sel` 去掉了,只给亮主留着)。
2. 局终点「复盘本局」之后,「下一局」按钮所在的区域被样式整个藏掉,**只能刷新页面**;同理「手动进入下一墩」和低分造反的按钮也看不见。
3. 窄屏底栏放不下,「扣底」被挤出屏幕右边,只能横向拖;版本号压在按钮上。
4. 开局前「出牌 / 清选 / 托管 / 问六六 / 扣底 / 看底牌」全都露在外面可以点。
5. 「问六六」打开一个盖住整张牌桌和手牌的抽屉,看建议时看不到牌。
6. 横屏局终面板的按钮在屏幕外;横屏菜单也被截断。
7. 记笔记的输入框点「存笔记」不会存(隐藏的发送按钮没有绑定)。

**难用的:**
- 每次重画手牌(每出一张、发牌每一张)整手牌都从左上角滑进来一次。
- 两位数「10」被下一张牌盖住只剩「1」;分牌标签在牌的右下角,手牌里看不到。
- 平板竖屏按「宽屏」排,牌小、下面一大片空白;电脑上顶栏挤在左边。
- 出错提示只念一遍规则(「需出 1 张;有本门必须跟,门内有对必对」),不说具体错在哪。
- 发牌时顶栏写「♦ 抢亮中」,看不出是谁亮的;扣底阶段桌上没有任何提示。
- 悔牌只在设置里能用;小王和大王一样红。

**不符合设计系统的:** 教练文字用旧版浅蓝 `#6ec9ff`、菜单和设置里用 emoji 当图标、
「重开整场」是红底主按钮、遮罩是灰色、页面里残留一整套隐藏的旧 DOM(重复 id)和五层互相覆盖的旧样式。

## 改法

- **样式整个重写**:只留六六头像一条,其余按 `design-system/`(暖纸、素绿桌、蜂蜜黄、墨描边 + 实心投影、药丸按钮)写成一份,
  不再引用 `components/bundle.css` / `bundle.js`(打牌页没用到)。文件从 742 KB 降到 675 KB。
- **三种骨架**:竖屏(手机、平板竖放)/ 矮横屏(手机横放,操作栏在手牌右侧)/ 宽屏(平板横放、电脑,内容最宽 1280)。
- **手牌排布**(表现层 `planHand`):按「牌尽量大、少分行、别要左右拨」打分,选 1~3 行和牌宽;
  一局里按 25 张定尺寸,发牌和出牌途中牌不忽大忽小;扣底 33 张单独算(手机上三行)。新建的手牌元素从上次的位置过渡过去。
- **桌面**:桌面牌宽按牌桌剩余空间算;桌心一块显示「发牌中 / 最后亮主机会 N 秒 / 扣底 n/8 / 轮到你领出 / 本墩 X 分」。
- **操作栏按阶段收**:发牌只有「托管」和「亮主 ♣」;扣底是「清选」+「扣底(n/8)」;出牌是「问六六 / 托管 / 悔牌」+「清选」+「出牌」;
  复盘、造反、手动下一墩的按钮重新露出来。「看底牌」移进菜单。
- **六六气泡**:「问六六」在手牌上方弹气泡:先出小测验(可跳过),再给「建议出 X —— 理由」,带「就出这手」「为什么」。
  出了明显更差的一手,气泡自动提醒 7 秒。
- **产品原件里改的几处**(只在这个测试页):牌面 HTML(分值标签、两位数、U+FE0E)、出错提示说具体哪一条、
  局终面板重排(得分徽章、底牌小牌、六六复盘、两队级数)、开局封面、设置里去掉 emoji 和红底按钮、
  `window.__undo` / `__canUndo`、停掉 `fitHandRow`(它的量尺寸会让新牌飞入)。规则、AI、教练判断一行没动。

## 验证

- 五个尺寸各打完整一局(托管)无报错;引擎自测 `#test` 219 通过 0 失败。
- 交互:亮主(点牌 → 「亮主 ♣」)、扣底选牌、出错提示、问六六 → 测验 → 就出这手、悔牌、上拖出牌、
  局终 → 看看这局(自动翻开记录)→ 下一局,都走通。
- 没做:真机触摸、iOS Safari、读屏器。

- 默认语言是「沪语版」术语(翻 / 灭底 / 撒牌 / 飞机大炮 / 老K),第一次玩的人看不懂;建议测试页默认普通话,或在封面让人选。
- 产品原件是 v0.7.39 的分叉,没有牌谱上传、教练文案也比测试版 v0.7.40 旧。真要上线需要按测试版重新同步一次。

## 第二轮(2026-10-20,产品方反馈)

- 上下家的名字钉住:按「名字 + 一摞牌」整体居中定好位置,牌摞挂在名字下面;矮横屏里对家、我的牌摞放在名字旁边。出不出牌名字都不动。
- 大小王换成猫头(`catSVG`):大王是蜂蜜黄脸、彩色耳朵与条纹、粉蓝双色圆底的波普猫,小王是灰白猫。牌面左上角小猫头 +「大 / 小」,牌面右下一只大猫头;对局记录里也用猫头。
- 对局记录:「第 x 墩」不再折行;每家出的牌各成一组、整组可以折行(甩牌、拖拉机、初始手牌、按花色都不再溢出);右边留出安全边距。
- 记牌表加回来,放进「六六教练」页签(可折叠,保留「先心算再对答案」);数据由产品原件 `window.__memData` 给,口径与原 `renderMemTab` 相同。
- 抽屉打开时手牌不再浮在抽屉上面(`#game` 自成层叠上下文)。
- 六六教练页:记笔记的输入框在最上面(吸顶),下面依次是记牌表、小测验、六六的话、笔记。输入框只建一次,打字时不会被每秒的刷新打断。
- 手机上点进输入框不再翻成横屏:软键盘把可视高度压低时不换骨架;抽屉、菜单靠哪边改由页面骨架决定(不再看 `orientation`);视口加 `interactive-widget=resizes-visual`。
- 左上角六六头像去掉圆框(头像本身不居中,套圆总是歪),改成沿轮廓的一圈墨线;封面、气泡、局终复盘里的头像同样处理。
- 竖屏顶栏改成两行网格,第一行永不折行(「下家亮 ♣ 对」这类长文案也放得下)。

## 第三轮(2026-10-20,手机试玩反馈)+ 端到端体检脚本

新加 **`test/play-ui-e2e.js`**:在 16 个真实设备尺寸(320×568 到 1440×900,含手机横屏、平板)上从开局打到第二局,
每个阶段、每种按钮组合量一次版面 —— 东西出没出屏、操作栏放不放得下、按钮文字有没有被截、名牌和桌心压没压、
弹窗按钮看不看得见、抽屉有没有横向溢出、手牌是不是浮在抽屉上;还会点选六六建议的一组牌,按住 0.4 秒再拖到桌心,看出没出去。
`node test/play-ui-e2e.js`(全部)、`--only=390x844`、`--shots=目录`(每步截图)。改这个页面之后跑一遍。

它在合并后的版本上一跑就复现了「底部按钮放不下」(390 宽要 459px),顺带查出:横屏操作栏按钮掉出屏幕、
顶栏文字被截、320 宽桌心压住我的牌、横屏开局封面按钮看不见、横屏六六气泡盖住操作栏。

- **底部操作栏**:问六六 / 托管 / 悔牌改成图标 + 小字的方块(问六六是「问」+ 头像的小药丸),清选和主按钮保留药丸;
  360 宽以下再收紧。托管中按钮变绿、写「托管中」(产品 render 会把它改回纯文字,表现层再换回图标)。低分造反的长按钮名缩成两个字。
  矮横屏里手牌这一行跟着操作栏两行按钮长高。
- **多张牌拖到牌桌出不去**:两个原因。① 先按住(出放大镜)再拖,手指滑到上一排没选的牌上,拖走的就变成那一张;
  现在要出的牌在按下那一刻就定了(按在已选的牌上 = 整组)。② 斜着往桌心拖(横屏、宽屏最自然的动作)或按住后再拖,
  手势一直停在放大镜 / 横扫状态,松手被忽略;现在手指离开手牌区往上就算拖牌,横扫只在手牌要左右拨时才启用。
  松手在手牌区上方任何地方(包括顶栏)都算出牌;没轮到你时提示「还没轮到你出牌」。
- **大小王**改用六六的头像轮廓(拿头像图当遮罩,不画五官):大王四色波普块 + 网点,小王灰色网点;牌面与对局记录同一套。
- 桌心放在对家那摞和我这摞的正中间,宽度不超过两侧座位之间的空当;「本墩 X 分」不折行。
- 竖屏顶栏把「对」改成重复花色(♦♦),窄屏不再截字;矮屏开局封面缩小头像、去掉第二行说明。

## 第四轮(2026-10-24,产品方:桌上的牌太小、手牌太大、桌心信息和牌互相遮挡)

改成**牌桌优先**的版面(UI 试验 06):

- **一把尺子定大小**:手牌先定(竖屏两行、整张露出,不再被操作栏切掉一截;宽屏一行,上限 94px),
  桌面牌宽 = 牌桌放得下的最大值,但不超过手牌的 1.25 倍。390×844 上手牌 61px、桌面牌 76px(原来是手牌 ~84、桌面 61)。
- **座位重新排**:名牌、四摞牌都由表现层按牌桌实际大小算好位置(`layoutTable()`),一局里名牌不动。
  竖屏 / 宽屏:对家名牌在上、牌摞挂下面;上下家名牌和对家那摞同一高度、左右错开(省出一行给牌),牌摞在名牌下面朝桌心长;
  我这摞在最下面正中。并排放不下一对时,上下家名牌退到单独一行。矮横屏:对家、我两摞在中间一列,名牌在牌摞左边。
  每摞有「最宽多宽」,甩牌、拖拉机多了只收紧叠放间距,不压别家。窄桌面(< 380px)名牌只留头像 + 名字。
  「庄 / 领 / 托管」改成贴在名牌右上角的小徽章,名牌宽度一局里不变(原来加个字名牌就变宽,靠右的会出桌)。
  矮屏(320×568、1024×768 这类)牌桌放不下时,手牌按屏幕尺寸让一点,让桌面牌至少有手牌的九成。
- **桌心不再放信息框**(它总是和牌抢地方):
  - 本墩分 → 顶栏得分条后面的「+N」,闲家暂时赢着这墩时进度条上用斜纹预览加上去以后到哪;
  - 轮到谁 → 那家名牌变黄、头像外转一圈;轮到我 → 我出牌的地方画虚线空位「轮到你 · 领出 / 跟牌」;
  - 谁领的 → 名牌上「领」字;收墩 → 「我方收 10 分」戳在赢的那摞上(不再盖在桌心);
  - 发牌、亮主、扣底这些还没出牌的阶段,桌心才有提示;桌心有亮主的牌就挪到空处。
- **看起来像牌桌**:名牌加头像(队友青色、对手棕色);桌布加内圈细线、中间亮四周暗、桌心淡淡的六六;
  整张露在桌上的牌右下角画大花色;出的牌从出牌人那边飞进来。
- 六六气泡:竖屏 / 宽屏盖在我出牌那一行(轮到我时那里空着);矮横屏只占上下家牌摞之间。
- e2e 的点牌改成点露出那一块的中间(贴边点会被手机的触摸纠偏吸到隔壁那张)。e2e 加了三项:四家各摆 2 / 4 / 6 张的**桌面压力**(名牌、牌摞两两不压、不出桌)、桌面牌不小于手牌的 80%、
  竖屏 / 宽屏手牌不被操作栏切掉。

## 第五轮(2026-10-24,产品方:再过一遍基础 → 基础动效 → 玩家占位)

**再过一遍基础**(手机竖屏、横屏、电脑,所有阶段的截图逐张看),改了这些:

- 名牌上的「领 / 庄」徽章压住名字 → 名牌改成「头像 + 名字 / 座位」两行,徽章贴在头像角上(领在左上、庄在右下、我托管时左下一个「托」),不占字的位置。
- 我的名牌只留一个头像(原来孤零零一个「我」字药丸)。
- 出错提示原来放在桌心,会盖住别家的牌 → 放在我出牌那一行(出错都发生在轮到我时,那里空着),再按候选点躲开牌摞和名牌。
- 对局记录看不出每组牌是谁出的 → 每组牌前面挂一个小头像。
- 局终面板:底牌八张原来折成 7 + 1 → 一行叠着放;矮横屏的紧凑样式原来被后面的基础样式盖掉,恢复;
  面板底部按钮条下面原来会漏出滚动内容,改成贴底。
- 六六考题的选项按钮收小一点,多数情况一行放得下。

**基础动效**(系统设了「减少动态效果」时全部关掉):

- 发牌、拿底牌:新来的牌从桌心飞进手牌。
- 收墩:一墩打完、桌子清掉时,四摞牌的影子一起飞向赢家的名牌、缩小淡出。
- 出牌:桌上的牌从出牌人那边飞进来(上一轮已有);收墩戳弹一下。
- 闲家得分涨了:分数跳一下、进度条闪一圈;桌上这一墩的「+N」弹出来。
- 轮到我:虚线空位弹出来;出错提示弹出并左右晃一下;弹窗弹出、遮罩淡入。

**玩家占位**:三位电脑玩家叫 **Bob(下家)/ Kevin(对家)/ Stuart(上家)**,头像先用首字母圆片
(队友青色、对手砖红、我蜂蜜黄),名字下面一行小字写座位。名字也用在桌心提示、对局记录、局终「下一局谁坐庄」里;顶栏亮主那块用小头像(名字长,窄屏放不下)。
六六只当教练,不上桌。六六和教练的文字里仍然说「上家 / 下家 / 对家」,所以名牌上一直保留座位那行小字。

## 第七轮(2026-10-25,产品方:横屏很有问题)+ #60 里的进度条语义色

逐张看了 568×320 / 667×375 / 844×390 / 932×430 各阶段的截图,横屏的问题:

- **顶栏折行**:568 宽「K 亮 无主」这类长一点的主牌提示一出来,菜单按钮就掉到第二行(e2e 原来只查竖屏顶栏)。
  → 横屏顶栏强制一行,窄于 700 时去掉左上角头像和「闲家」两个字、级数写成「我 2 | 对 2」。
- **操作栏和手牌抢一行**:按钮栏占右边四分之一,手牌只剩三分之二宽,常分两排、下排被屏幕底边切掉一半。
  → 按钮改成牌桌右边一条两列的竖栏(问 / 托管 / 悔牌 / 清选 两两一排,主按钮占整行在最下面,亮主、扣底等按钮也在这里);
  手牌占满整个屏幕宽,排一行,贴着屏幕底边。
- **「我」的头像浮在桌子正中**:→ 挪到牌桌左下角(和竖屏一致)。
- **568 宽桌面太窄**:上下家名牌放在牌摞旁边连一对都放不下时,名牌退到上面两角、牌摞挂在名牌下面,桌面牌宽也按放得下一对来算。
