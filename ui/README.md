# 80 分 · 竖屏交互实验 02

独立于现有游戏的手机原型。所有修改在 `ui/` 内，规则引擎继续复用主仓库。

入口为 `ui/index.html`，跳转到真正的牌桌 `dist/index.html`。手机直接打开页面，没有套娃 iframe 或整体缩放。电脑显示同一个最大宽度 460px 的界面。`dist/lab.html` 是单独的尺寸实验室，保持 320×568、375×667、390×844、430×932 的真实 CSS 像素，不缩放。

## 这次推翻了什么

取消绿毡桌面、四角座位和四条细小手牌。改为上方三家出牌、下方按花色切换的大牌网格，以及独立固定的操作区。默认跟牌时直接打开该跟的花色，全手牌视图可浏览和跨花色选牌。

- 手牌四列，320px 屏宽时每张 68×82px 起，牌面不重叠。
- 出牌按钮高 60px，清空按钮宽 64px；花色切换按钮至少高 48px。
- 手牌区自己纵向滚动，底部操作区不跟着滚走。
- 切换花色、进入或关闭全手牌视图都保留选择；全手牌视图可直接确认出牌/扣底。
- 提交后扣除选中物理牌，显示由引擎算出的真实墩分和累计分。

## 演示范围

固定局面：跟对子、领出拖拉机、33 张拿底扣底。支持点选/取消、清空、规则校验、确认提交、看本墩、重置/换局面。此版不运行完整对局，不模拟对手后续出牌，也未接入 LLM；暂不演示甩牌、亮主和升级流程。

`dist/engine.js` 提取自主仓库 `ca7ffe56097fc63692fbc11120eeaed80e3e9ef2` 的 `index.html` 第一个 script 块，仅添加浏览器导出。通过 `isLegalFollow`、`classify`、`resolveTrick` 验证演示动作，更新主线时需重新提取。

## 文件与运行

- `dist/index.html`、`table.css`、`table.js`：原型主体。
- `dist/table.html`：旧地址兼容跳转。
- `dist/lab.html`、`lab.css`：独立尺寸实验室。
- `dist/DESIGN.md`：设计取舍和待验证项。
- `tests/interaction.cjs`：不依赖浏览器的交互状态与规则测试；不代替触屏测试。
- `.openai/hosting.json`：原型的私有预览配置。

运行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory ui/dist` 后，打开 `http://127.0.0.1:8765/`。测试：`node --test ui/tests/interaction.cjs`。
