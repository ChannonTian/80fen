独立于现有游戏，修改仅在 `ui/`。入口 `ui/index.html` 跳转至 `dist/index.html`；默认根据窗口自动使用竖屏或宽屏牌桌。竖屏最大宽度 520px，宽屏最大宽度 1600px。没有对整张牌桌做缩放。

`dist/index.html?layout=wide` 是横屏/大屏入口，`?layout=portrait` 保留竖屏对照，`?layout=auto` 自动适配。菜单可直接切换，保留局面与已选牌。

## 本轮交付：共用牌桌与两类学习模板

- 课程页：六六与进度环同心；紧凑进度头与继续按钮；牌面选中预览，牌内开始/复习按钮进入；仅当前课抬起且维持扇形角度；锁定单元默认收起。
- 打牌页：六六独立为教练；座位标明队友/对手；桌心合并跟牌提示和墩分；亮主牌归属到亮主方；统一牌点和花色比例。
- 学习页：有牌桌的情境练习、无牌桌的专注练习。其他玩家手牌只在作为明牌证据时出现；认牌在自己的扇形手牌选择，玩家/队伍直接在桌面选择，甩牌判断在桌心完成。
- [设计标准与题型对照](dist/LEARNING-DESIGN.md)记录上述规则及验收边界。`dist/templates.html` 保留 13 种判题类型、73 个样例，但共用两个布局骨架。
- 全部修改仅在 `ui/`，没有重写正式游戏或教学。`scripts/study-surface.js` 是表现适配，原题库和判题规则复用既有来源。

验证：两个紧凑尺寸 320×568、844×390 遍历全部 73 个样例，无页面滚动或卡牌/选项越界；收墩、辨认牌等实际点选提交通过；19 项现有检查通过。完整记录见设计笔记。

生成教学页：`python3 ui/scripts/refresh-learn-preview.py`；固定来源提交为 `5a143095f1163be2be3302e342753abce6f8109e`。主仓库根目录页面保持原样。字体使用 PingFang SC / Noto Sans SC / Microsoft YaHei，未加载网络字体。

六六（Leo-Leo）是暖棕虎斑、深色鼻头、金黄色眼睛的猫教练。头像资源保留在 `dist/assets/leo-leo-expressions.png`，角色设定见 `characters/leo-leo.md`。

## 横屏扩展

- 手机横屏：单行状态栏、单层扇形手牌、工具与拨动条合并到底部。
- 平板/桌面：扩大牌桌和牌面，33 张手牌宽度足够时单层展开；平板窄向可保留双层。
- 触控/鼠标都沿用点选与拖牌流程，桌边仍可点击提交。
- 尺寸实验室新增手机横屏、平板横竖屏与桌面；切换尺寸不重开局。

## 空间与操作

- 模拟玩家视角：对家在前，两家在左右；出牌堆叠，暂大方高亮，墩分放在桌面中间。
- 全手牌按有效花色与大小理成两层扇形，每张牌保持独立身份，分层尽量不断开对子。
- 牌互相覆盖，只露左侧牌点与花色。窄屏保持至少 23px 的横向间距，用手牌下方拨动条查看两端。
- 点按选牌并升起 24px；按住左右滑动放大查看，松手选中当前牌。
- 从选中牌上拖带走整组；进入桌面并松手后，合法牌组才提交。桌外松手保留选择，触摸取消恢复开始拖动前的选择。
- 桌沿保留点击出牌作为替代操作；底栏用于底牌、清选、理牌、展牌或埋底。
- 亮主、加固、反主在发牌演示阶段提供大按钮，使用规则引擎校验权限。

## 演示范围

菜单提供五个固定局面：25 张跟对子、领出拖拉机、33 张拿底扣底、亮主后加固、反别人的主。支持两种出牌方式，实际计算墩分和剩余牌数。仍不是完整游戏，不模拟后续发牌、对手决策、甩牌、升级结算或抢主网络竞态。

`dist/engine.js` 提取自主仓库 `ca7ffe56097fc63692fbc11120eeaed80e3e9ef2` 的 `index.html` 第一段脚本，仅增加浏览器导出。原型不另写出牌与亮主规则。
