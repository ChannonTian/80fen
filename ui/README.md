# 80 分 · 六六陪你打牌 06

独立于现有游戏，修改仅在 `ui/`。入口 `ui/index.html` 跳转至 `dist/index.html`；默认根据窗口自动使用竖屏或宽屏牌桌。竖屏最大宽度 520px，宽屏最大宽度 1600px。没有对整张牌桌做缩放。

`dist/index.html?layout=wide` 是横屏/大屏入口，`?layout=portrait` 保留竖屏对照，`?layout=auto` 自动适配。菜单可直接切换，保留局面与已选牌。

## 本轮风格统一

这一版围绕六六统一暖纸色、棕色轮廓和素绿牌桌。新增 `dist/leo-theme.css` 统一角色、模式导航、按钮和牌桌；`dist/study-layout.css` 负责学习首页与练习响应式布局。

- 牌桌：六六坐在对家，点击头像可打开当前演示局面的规则提示；其余角色暂用座位标识。提示为预设讲解，未接大模型。
- 课程入口：突出下一课、实际学习进度、单课时长；逐课展示已学、当前与锁定状态，已学课程可单独重练。
- 练习页：六六的名字与表情持续陪伴；大屏讲解在左、操作在右，手机保持上下布局。
- 学习地图由 `scripts/study-map.js` 提供，刷新教学预览时自动接入；原有题库、判题与进度存储逻辑保留。

本轮检查：本地浏览器查看 390×844 竖屏、844×390 横屏和 1180×820 大屏；点击六六提示、进入课程、选答案和反馈流程通过。11 项现有规则/交互检查通过，课程初始、下一单元与全部完成状态另做脚本检查。浏览器尺寸模拟不等于真机触控验证。

以主仓库现有教学页为基准：浅色页面、素色桌面、白牌、圆润无衬线数字；去掉深色材质、金边、发光及牌面中央花色。蓝色统一表示选择，绿色表示主要动作/正确/领先。

游戏页加载 `dist/theme.css`，教学对照页 `dist/learn.html` 复用同一主题并加载 `dist/learn-theme.css`。两页有互相进入的链接，教学进度使用独立前缀。详细取舍见 `dist/STYLE.md`。

猫教练是第一个主要角色六六（Leo-Leo），依据用户提供的实拍照片绘制：暖棕虎斑、深色鼻头、金黄色眼睛；同一张图保留日常、答对、思考三种表情。头像位于 `dist/assets/leo-leo-expressions.png`，由教学预览生成脚本接入，重新生成页面也会保留。角色特征记录在 `characters/leo-leo.md`，后续角色参考同一画风。

教学对照来自主仓库最新读取版本 `5a143095f1163be2be3302e342753abce6f8109e`，保留课程及判题逻辑。可用 `python3 ui/scripts/refresh-learn-preview.py --ref <明确的提交>` 重新生成；脚本在来源结构变动时会停止并提示检查适配点。没有改动仓库根目录的 `learn.html`。

## 横屏扩展

- 手机横屏：单行状态栏、单层扇形手牌、工具与拨动条合并到底部。
- 平板/桌面：扩大牌桌和牌面，33 张手牌宽度足够时单层展开；平板窄向可保留双层。
- 触控/鼠标都沿用点选与拖牌流程，桌边仍可点击提交。
- 尺寸实验室新增手机横屏、平板横竖屏与桌面；切换尺寸不重开局。

## 空间与操作

- 模拟玩家视角：对家在前，两家在左右；出牌堆叠，暂大方高亮，墩分放在桌面中间。
- 全手牌按有效花色与大小理成两层扇形，每张牌保持独立身份，分层尽量不断开对子。
- 牌互相覆盖，只露左侧牌点与花色。窄屏保持至少 23px 的横向间距，用手牌下方拨动条查看两端。
- 点按选牌并升起 24px；按住左右滑动放大查看，松手选中当前牌。
- 从选中牌上拖带走整组；进入桌面并松手后，合法牌组才提交。桌外松手保留选择，触摸取消恢复开始拖动前的选择。
- 桌沿保留点击出牌作为替代操作；底栏用于底牌、清选、理牌、展牌或埋底。
- 亮主、加固、反主在发牌演示阶段提供大按钮，使用规则引擎校验权限。

## 演示范围

菜单提供五个固定局面：25 张跟对子、领出拖拉机、33 张拿底扣底、亮主后加固、反别人的主。支持两种出牌方式，实际计算墩分和剩余牌数。仍不是完整游戏，不模拟后续发牌、对手决策、甩牌、升级结算或抢主网络竞态。

`dist/engine.js` 提取自主仓库 `ca7ffe56097fc63692fbc11120eeaed80e3e9ef2` 的 `index.html` 第一段脚本，仅增加浏览器导出。原型不另写出牌与亮主规则。
