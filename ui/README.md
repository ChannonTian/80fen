# 80 分 · 竖屏手牌实验 03

独立于现有游戏，修改仅在 `ui/`。入口 `ui/index.html` 跳转至 `dist/index.html`；直接手机打开是满屏牌桌，桌面最大宽度 520px。没有对整张牌桌做缩放。

## 新的空间与操作

- 模拟玩家视角：对家在前，两家在左右；出牌堆叠，暂大方高亮，墩分放在桌面中间。
- 全手牌按有效花色与大小理成两层扇形，每张牌保持独立身份，分层尽量不断开对子。
- 牌互相覆盖，只露左侧牌点与花色。窄屏保持至少 23px 的横向间距，用手牌下方拨动条查看两端。
- 点按选牌并升起 24px；按住左右滑动放大查看，松手选中当前牌。
- 从选中牌上拖带走整组；进入桌面并松手后，合法牌组才提交。桌外松手保留选择，触摸取消恢复开始拖动前的选择。
- 桌沿保留点击出牌作为替代操作；底栏用于底牌、清选、理牌、展牌或埋底。
- 亮主、加固、反主在发牌演示阶段提供大按钮，使用规则引擎校验权限。

## 演示范围

菜单提供五个固定局面：25 张跟对子、领出拖拉机、33 张拿底扣底、亮主后加固、反别人的主。支持两种出牌方式，实际计算墩分和剩余牌数。仍不是完整游戏，不模拟后续发牌、对手决策、甩牌、升级结算或抢主网络竞态。

`dist/engine.js` 提取自主仓库 `ca7ffe56097fc63692fbc11120eeaed80e3e9ef2` 的 `index.html` 第一段脚本，仅增加浏览器导出。原型不另写出牌与亮主规则。

## 文件与验证

- `dist/index.html`、`table.css`、`table.js`：牌桌与交互。
- `dist/fan.js`：纯函数扇形排布、分层与手势阈值。
- `dist/lab.html`、`lab.css`：独立尺寸实验室，320×568 至 430×932。
- `dist/DESIGN.md`：参考、设计取舍与验证边界。
- `tests/interaction.cjs`：规则、状态、指针事件处理和几何计算检查；不是浏览器排版或真机触控测试。
- `.openai/hosting.json`：独立原型的私有预览配置。

本地：`python3 -m http.server 8765 --bind 127.0.0.1 --directory ui/dist`，打开 `http://127.0.0.1:8765/`。

测试：`node --test ui/tests/interaction.cjs`。
